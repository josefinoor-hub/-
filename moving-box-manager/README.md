# 📦 ניהול ארגזים למעבר דירה

אפליקציית PWA לניהול אריזת ארגזים במעבר דירה: מספור אוטומטי, קודי QR, חיפוש
מיידי, הדפסת מדבקות וסנכרון בין כל המכשירים במשפחה — גם כשאין קליטה.

---

## מה האפליקציה עושה

| יכולת | פירוט |
|---|---|
| מספור אוטומטי | `BOX-001`, `BOX-002`… רציף וייחודי, גם כששני מכשירים אורזים במקביל |
| 17 חדרים מוגדרים | בחירה בהקשה אחת, כל חדר עם צבע ואייקון משלו |
| תכולה חופשית | רשימת פריטים מופרדת בפסיקים, מוצגת כתגיות |
| סימונים | שביר (כן/לא), עדיפות פריקה (גבוהה/רגילה) |
| קוד QR | נוצר אוטומטית לכל ארגז, מקודד מזהה + חדר + תמצית תכולה |
| חיפוש מהיר | לפי פריט, חדר או מספר ארגז — תוצאות תוך כדי הקלדה |
| סריקה | פתיחת כרטיס הארגז ישירות ממצלמת המכשיר |
| הדפסת מדבקות | 50×30 מ"מ, 100×60 מ"מ, גיליון A4 (8 בעמוד), ומדפסת תרמית ב-Bluetooth |
| עבודה ללא רשת | הכול עובד אופליין ומסתנכרן אוטומטית עם חזרת הקליטה |
| גיבוי | הגיליון מגובה ל-Google Drive, אוטומטית כל יום או בלחיצה |

## ארכיטקטורה

```
┌──────────────┐   ┌──────────────┐   ┌──────────────┐
│  טלפון יוסי   │   │ טאבלט המשפחה │   │  טלפון נוסף   │
│   PWA + מטמון │   │  PWA + מטמון │   │  PWA + מטמון │
└───────┬──────┘   └──────┬───────┘   └──────┬───────┘
        │                 │                  │
        └────────── HTTPS / JSON ─────────────┘
                          │
             ┌────────────▼─────────────┐
             │  Google Apps Script      │  ← יישוב התנגשויות, מספור, גיבוי
             │  (Web App על הגיליון)    │
             └────────────┬─────────────┘
                          │
             ┌────────────▼─────────────┐
             │  Google Sheets ב-Drive   │  ← מקור האמת + גיבוי יומי
             └──────────────────────────┘
```

**עקרון מנחה:** המטמון המקומי (IndexedDB) הוא מקור האמת של הממשק, והגיליון הוא
מקור האמת המשותף. כל פעולה נשמרת מיידית במכשיר ונדחפת ברקע — ולכן האפליקציה
לעולם לא "נתקעת" בגלל רשת איטית.

## התקנה — שלב אחר שלב

### שלב 1: הקמת הגיליון והשרת (פעם אחת, 5 דקות)

1. היכנסו ל-[Google Drive](https://drive.google.com) עם חשבון המנהל
   (`josefinoor@gmail.com`) וצרו **גיליון אלקטרוני חדש**. תנו לו שם, למשל
   "ניהול ארגזים — מעבר דירה".
2. בתפריט הגיליון: **Extensions ← Apps Script**.
3. מחקו את הקוד שמופיע בעורך, והדביקו במקומו את כל התוכן של
   [`backend/Code.gs`](backend/Code.gs). שמרו (💾).
4. בראש העורך בחרו בפונקציה **`setup`** ולחצו **Run**.
   * בפעם הראשונה תתבקשו לאשר הרשאות: **Review permissions ← בחרו את החשבון ←
     Advanced ← Go to … (unsafe) ← Allow**. זה תקין — אתם מאשרים לסקריפט
     שכתבתם לגשת לגיליון שלכם.
   * הפעולה יוצרת את הגיליון `Boxes`, מייצרת **מפתח גישה** ומתקינה גיבוי יומי.
5. פתחו **Execution log** (למטה) והעתיקו את מפתח הגישה שמודפס שם.
   אפשר להציג אותו שוב בכל רגע בהרצת הפונקציה `showToken`.
6. לחצו **Deploy ← New deployment**:
   * **Select type** (גלגל השיניים) ← **Web app**
   * **Execute as:** `Me`
   * **Who has access:** `Anyone`
   * **Deploy** ← העתיקו את ה-**Web app URL** (מסתיים ב-`/exec`).

> 🔒 **חשוב:** הפריסה פתוחה לכל מי שמחזיק בכתובת, ולכן הכתובת ומפתח הגישה הם
> סוד. אל תפרסמו אותם. אפשר לבטל גישה בכל רגע דרך **Deploy ← Manage deployments
> ← Archive**, או להחליף מפתח שנחשף בהרצת הפונקציה `resetToken` (ואז לעדכן את
> המפתח החדש בכל המכשירים).

### שלב 2: פרסום האפליקציה

האתר מפורסם ב-Netlify מהמאגר הזה. אחרי דחיפת הקוד, האפליקציה זמינה בכתובת:

```
https://<שם-האתר-שלכם>.netlify.app/moving-box-manager/
```

אין צורך בשלב build — האפליקציה בנויה מקבצים סטטיים בלבד.
לבדיקה מקומית לפני פרסום:

```bash
cd moving-box-manager
python3 -m http.server 8123
# ואז לפתוח http://localhost:8123
```

> המצלמה, ההתקנה כאפליקציה וה-Bluetooth דורשים **HTTPS** (או `localhost`).
> ב-Netlify זה מובנה.

### שלב 3: חיבור המכשיר הראשון

1. פתחו את כתובת האפליקציה ב-**Chrome** בטלפון.
2. מסך ההגדרות ייפתח אוטומטית. הדביקו:
   * **כתובת שרת** — ה-Web app URL מהשלב הקודם
   * **מפתח גישה** — המפתח שהעתקתם
3. לחצו **שמירה ובדיקה**. הודעת "החיבור הצליח" מאשרת שהכול תקין.
4. בתפריט של Chrome (⋮) בחרו **הוספה למסך הבית** — האפליקציה תיפתח מעכשיו
   כאפליקציה רגילה, במסך מלא.

### שלב 4: חיבור שאר המכשירים (10 שניות למכשיר)

1. במכשיר שכבר מחובר: **הגדרות ← 📱 חיבור מכשיר נוסף**.
2. במכשיר החדש: סרקו את קוד ה-QR שמוצג במצלמה הרגילה.
3. האפליקציה תיפתח כשהיא כבר מחוברת לגיליון המשפחתי. הוסיפו למסך הבית.

### שלב 5: הדפסה

**מדפסת רגילה / Wi-Fi / PDF** — לוחצים **🖨️ הדפס מדבקה**. נפתח מסך ההדפסה של
אנדרואיד: אפשר לבחור מדפסת ברשת, או **שמירה כ-PDF** לשליחה לחנות דפוס.
בחרו מידה לפני ההדפסה: `50×30`, `100×60` או גיליון `A4` (8 מדבקות בעמוד —
הכי חסכוני להדפסה מרוכזת של חדר שלם דרך 🖨️ שליד שם החדר).

> בדיאלוג ההדפסה של אנדרואיד כדאי לוודא ש**"התאמה לעמוד" (Fit to page) כבויה**
> וש"שוליים" מוגדרים ל-None, כדי שהמדבקה תצא בגודל המדויק.

**מדפסת תרמית ניידת (Bluetooth)** — לוחצים **📶 מדפסת תרמית**, בוחרים את
המדפסת ברשימה, וזהו. המדבקה נשלחת כתמונה בפרוטוקול ESC/POS, ולכן העברית
יוצאת מושלמת גם במדפסות שאין בהן גופן עברי. דורש Chrome לאנדרואיד.

## שימוש יומיומי

* **אריזה:** לוחצים **הוסף ארגז חדש** ← בוחרים חדר ← מקלידים מה נכנס ←
  **שמירה והוספת עוד** ממשיך ישר לארגז הבא. מדביקים מדבקה, ממשיכים.
* **חיפוש "איפה הקומקום?":** מקלידים "קומקום" בשורת החיפוש — הארגז קופץ מיד.
* **בפריקה:** סורקים את ה-QR שעל הארגז (📷) ורואים מה בפנים בלי לפתוח.
* **מיון לפי חדר:** תצוגת "לפי חדרים" מראה כמה ארגזים בכל חדר; אפשר לקפל חדרים.

## איך הסנכרון עובד (ולמה זה אמין)

* **דו-כיווני:** כל שינוי נדחף לשרת תוך פחות משנייה, וכל מכשיר מושך שינויים
  כל 6 שניות — ומיד כשחוזרים למסך או כשהרשת חוזרת.
* **התנגשויות:** אם שני מכשירים ערכו את אותו ארגז, מנצחת העריכה עם חותמת הזמן
  המאוחרת יותר. ההכרעה נעשית בשרת, כך שכל המכשירים מגיעים לאותה תוצאה.
* **מחיקה רכה:** ארגז שנמחק מסומן `deleted` ולא נעלם מהגיליון — כך המחיקה
  מסונכרנת לשאר המכשירים, ואפשר לשחזר ידנית בגיליון.
* **מספור ללא התנגשות:** כל מכשיר משריין מראש בלוק של 40 מספרים. לכן גם בלי
  קליטה הארגז מקבל מספר סופי מיד וניתן להדפיס לו מדבקה במקום.

## מגבלות ידועות

* **"זמן אמת" = עד כ-6 שניות.** Google Apps Script אינו יכול לדחוף עדכונים
  למכשירים, ולכן הסנכרון מבוסס משיכה מהירה ולא על חיבור מתמיד. למי שצריך
  עדכון מיידי ממש אפשר להחליף את `js/api.js` במימוש מול Firebase Realtime
  Database — שאר הקוד לא משתנה.
* **סריקת QR** מסתמכת על `BarcodeDetector` (Chrome לאנדרואיד). בדפדפן שאינו
  תומך מוצגת הקלדה ידנית של מספר הארגז במקום המצלמה.
* **הדפסה תרמית** דורשת Web Bluetooth — קיים ב-Chrome לאנדרואיד, לא ב-iOS.
* **אבטחה** מבוססת על סודיות הכתובת והמפתח, בהתאם למודל של פריסת Apps Script
  ציבורית. מתאים לשימוש משפחתי, לא לנתונים רגישים.
* **מכסות Apps Script:** מכשיר עם האפליקציה פתוחה על המסך פונה לשרת כ-600
  פעמים בשעה (פנייה כל 6 שניות), וכשהאפליקציה ברקע — פי עשרה פחות. לחשבונות
  Google יש מכסות שימוש יומיות; אם מריצים הרבה מכשירים לאורך כל היום וצצות
  שגיאות סנכרון, מגדילים את `SYNC.POLL_INTERVAL_MS` ב-`js/config.js`.

## פיתוח ובדיקות

האפליקציה עצמה נטולת תלויות ואינה דורשת שלב build. הבדיקות רצות ב-Node:

```bash
node tools/qr-test.mjs        # מקודד ה-QR
node tools/backend-test.mjs   # חוזה השרת (Code.gs נטען עם תחליפים לשירותי Google)
```

בדיקות הדפדפן (אופציונליות, דורשות `npm install playwright`) מריצות את
האפליקציה מקצה לקצה מול שרת דמה — בלי לגעת בגיליון האמיתי:

```bash
node tools/e2e/mock-server.mjs &            # שרת דמה בפורט 8124
python3 -m http.server 8123 &               # מגיש את האפליקציה
node tools/e2e/app-test.mjs                 # זרימות משתמש: אריזה, חיפוש, הדפסה, סנכרון
node tools/e2e/sync-test.mjs                # סמן הסנכרון ועבודה ללא רשת
```

מקודד ה-QR נכתב מאפס (ללא ספריות) ואומת מול מקודד הייחוס `segno` — התאמה
מלאה בקיבולת בכל 160 צירופי הגרסה/רמת התיקון — ומול המפענחים `zbar`
ו-OpenCV, כולל טקסט עברי ב-UTF-8.

**שינויים נפוצים:**

| מה לשנות | איפה |
|---|---|
| רשימת החדרים, צבעים ואייקונים | `js/config.js` → `ROOMS` |
| מידות מדבקה | `js/config.js` → `LABEL_SIZES` + `css/app.css` |
| קצב הסנכרון | `js/config.js` → `SYNC.POLL_INTERVAL_MS` |
| עיצוב המדבקה | `js/label.js` → `renderLabelHtml` + `.label` ב-CSS |

לאחר שינוי בקבצי ה-JS יש להעלות את מספר הגרסה ב-`sw.js` (`CACHE_NAME`)
כדי שהמכשירים יקבלו את הגרסה החדשה.

## פתרון תקלות

| תסמין | פתרון |
|---|---|
| "השרת החזיר תשובה לא צפויה" | הפריסה אינה `Anyone`, או שהכתובת אינה מסתיימת ב-`/exec` |
| "מפתח גישה שגוי" | המפתח באפליקציה שונה מזה שבסקריפט — הריצו `showToken` והעתיקו שוב |
| שינויים לא מגיעים למכשיר אחר | בדקו את מחוון הסנכרון בראש המסך; "לא מקוון" = השינויים ממתינים ויישלחו לבד |
| המדבקה יוצאת בגודל לא נכון | בדיאלוג ההדפסה: שוליים None, ו"התאמה לעמוד" כבויה |
| המצלמה לא נפתחת | נדרש HTTPS ואישור הרשאת מצלמה לאתר בהגדרות Chrome |
| עדכנתי קוד ולא רואים שינוי | העלו את `CACHE_NAME` ב-`sw.js`, ואז סגרו ופתחו את האפליקציה |
